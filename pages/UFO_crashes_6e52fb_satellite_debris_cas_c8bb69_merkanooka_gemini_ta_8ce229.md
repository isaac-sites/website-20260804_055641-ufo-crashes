## Introduction

The so-called Merkanooka Ball is one of the clearest examples of how an apparently mysterious object associated with UFO speculation was ultimately identified as ordinary—though unusual—aerospace hardware. Found near Merkanooka in Western Australia in September 1965, the large hollow metal sphere initially attracted official attention because its origin was unknown. Rather than remaining an unsolved curiosity, however, it underwent a methodical technical investigation. Australian defence scientists examined its construction, concluded that it was almost certainly American space hardware, and eventually NASA identified it as a pressure vessel from the Gemini 5 mission.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

## Discovery of the metal sphere in Western Australia

The object was reportedly found on 10 September 1965 near Merkanooka, an agricultural district in Western Australia, only days after NASA's Gemini 5 mission had concluded. It was a robust metallic sphere roughly 20 inches (about 51 cm) in diameter, built to withstand high pressure rather than aerodynamic flight. Unlike an aircraft fuel tank or ordinary industrial vessel, it exhibited specialised aerospace manufacturing techniques that immediately suggested it was not a local object.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

Because its origin could not be established locally, Australian authorities treated the discovery seriously. The Joint Intelligence Bureau requested technical analysis, and the Weapons Research Establishment (WRE)—Australia's principal defence research laboratory—received the sphere for examination in October 1965. Rather than assuming it represented something exotic, investigators focused on identifying its materials, construction and probable purpose.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

## The design clues that identified a spacecraft tank

The investigation succeeded because the sphere possessed several distinctive engineering characteristics that matched known spacecraft hardware.

Among the most important clues were:

* **Spherical pressure-vessel design.** The object was engineered to contain pressurised fluids rather than function as structural airframe material.
* **Heat-resistant construction.** Its materials were consistent with components capable of surviving atmospheric re-entry better than lighter aluminium spacecraft structures.
* **Specialised fittings and welds.** The manufacturing methods resembled those used in American spaceflight hardware rather than industrial storage equipment.
* **Dimensions matching Gemini components.** Its size closely corresponded to pressure tanks used within the Gemini spacecraft's Orbital Attitude and Manoeuvring System (OAMS).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

By April 1966, the WRE concluded internally that the object was "certainly of USA origin" and probably formed part of a space vehicle. This narrowed the possibilities dramatically, allowing the investigation to move from identifying its general class to matching it with a specific mission.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

## How investigators traced it to Gemini 5

The decisive identification came after cooperation between Australian authorities and the United States.

Australian records show that, after examination, the sphere was forwarded through defence channels to Washington for NASA's assessment. NASA concluded that the object originated from the Gemini 5 mission and identified it specifically as a 20-inch OAMS fuel tank that had been repurposed as a water storage tank within the spacecraft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufos-scientificresearch.blogspot.com/2013/01/mystery-spheres-found-in-australia.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blogspot.com">[UFOs Scientific Research]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blogspot.com</span><span class="citation-popover-title">UFOs Scientific Research Unidentified Anomalous Phenomena</span><span class="citation-popover-snippet">UFOs Scientific ResearchUnidentified Anomalous Phenomena - scientific research: &quot;Mystery spheres found in Australia&quot;January 25, 2013</span></span></span>

This conclusion was technically plausible for several reasons.

First, Gemini 5 introduced hydrogen-oxygen fuel cells to support an eight-day mission, replacing the battery-only approach used on earlier flights. Fuel cells generated water as a by-product, making onboard water storage an integral part of the spacecraft's systems.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/missions/gemini/55-years-ago-gemini-5-sets-a-new-record/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">55 Years Ago: Gemini 5 Sets a New Record</span><span class="citation-popover-snippet">55 Years Ago: Gemini 5 Sets a New Record - NASA...</span></span></span>

Second, pressure vessels are among the spacecraft components most likely to survive atmospheric re-entry. Their thick walls and compact geometry enable them to endure heating that destroys lighter structural panels and equipment. ## What the Merkanooka Ball demonstrates

The Merkanooka Ball has become a useful historical example because it shows how genuine space hardware can initially resemble a "mystery object" before careful analysis reveals a conventional explanation.

Rather than diminishing the fascination of the discovery, the identification highlights the sophistication of the investigation itself. Australian defence scientists recognised that the object was neither ordinary scrap nor an unknown phenomenon, but a recoverable piece of the early Space Age. NASA's subsequent identification linked it directly to one of the United States' landmark Gemini missions, transforming what might have remained a UFO anecdote into a documented case of recovered spacecraft debris.       button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
